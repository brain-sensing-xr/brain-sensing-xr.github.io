# New Frontiers in XR: Sensing the Brain — IEEE VR 2027 Workshop Website

This is a free static website built from the provided workshop proposal (September 28, 2026) and call for contributions. No installation, build step, paid hosting, or external assets needed.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (example: `brain-sensing-xr-workshop`).
2. Upload `index.html` to the repository root (GitHub > Add file > Upload files). Commit.
3. Go to **Settings > Pages > Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, and Save.
4. The address will be `https://YOUR-USERNAME.github.io/brain-sensing-xr-workshop/`.
5. Edit `index.html` in GitHub as your workshop details evolve.
